## 1. 单元概览

DirTree 是 BC 目录比较的**唯一引擎核心**（所有其他 Dir 单元都引用它），自身只依赖 S 地基与 BcJobs。

   `FUN_1406797b0`(SsMapTree 载荷基址) 访问。节点状态机 `FUN_140f4e530` 把状态字映射为 `Dir*` 枚举。
2. **文件夹构建（多路归并 + 递归）**：`FUN_140f54680` / `FUN_140f51580` / `FUN_140f536f0` 三档归并，
   节点工厂 `FUN_140f433f0`，挂树 `FUN_140f50dc0`，刷新入口 `FUN_140f51120`。
3. **两个后台 Job 类**：`TDirBuildFolderJob`（构造器 `140f509a0`，753 B）与
   `TDirTreeContentSearchJob`（构造器 `140f569f0`，410 B），经 BcJobs(`FUN_140dd6620` 注册类名→u16 id)
   登记；另有一组**每节点 Job 槽**（`FUN_140f4cb50` 懒建，tree+0xd8+side*8）。
4. **比较判定**：叶子状态 `FUN_140f4bf50`（两侧条目逐项比较 → 状态字）、目录聚合 `FUN_140f4c670`
   （子项计数器按位 OR）、内容搜索 Job 的逐条比较 `FUN_140f56570`。
5. **视图/会话协同**：`FUN_140f41b90`(清空/复位)、`FUN_140f470f0`(应用选项变更)、

## 3. 状态枚举与判定（核心）

### 3.1 编码规律（本单元最重要的发现）

`FUN_140f4e530` 末尾两行给出编码骨架：

```
if (local_50 == 0x13E && FUN_140f4e4e0(tree,node)) local_50 = 0x0C;   // DirUnknown → DirHollow
if (FUN_140679890(tree,node)) local_50 += 1;                          // Expanded → +1
```

`FUN_140679890` = `节点+0x11==0 && 节点+0x12!=0` = **目录节点且已展开**。故：

> **状态值 = 2 × 逻辑状态 + Expanded**（偶数 = 折叠，奇数 = 展开）；
> **逻辑状态 = 0x80 + code**（code 5..31），DirHollow(0x0C) 独在家族之外。

### 3.3 状态字的生产者

**叶子**：`FUN_140f4bf50(tree, node)`（1742 B，唯一调用者 `140f4ad40`）→ 产出状态码 0..0xD：

### 8.2 叶子状态字构造（谜题 #10 解答）

`FUN_140f4e530` 对**叶子**节点的执行路径：

```c
uVar6 = FUN_140f4f950(param_1, param_2);   // 读出叶子状态码 0..13
FUN_14000f790(local_48, uVar6, 2);          // SetBit(buf, code, elemSize=2)
uVar7 = local_48[0];                        // 16 位状态字
```

**结论：叶子状态字 = `1 << 状态码`（单热位图），不是枚举值。**
`FUN_14000f790` = `SetBit(buf, bitIndex, elemSize)`（SsClasses 单元；同类用法见
`SetBit(&local_38, param_2, 0x10)` 用于字符集位图）。

这解释了 §8.1 中所有掩码为何是**位**而非值：`uVar7 & 0x0428` 是在问
"左/右两侧的较新位是否置起"。**同一状态字可同时携带多个状态位**（如 bit3 与 bit6 并存 =
"左侧较新 且 右侧孤儿"），这正是 `DirNewerOrphan`(0x130) 这类复合状态的来源。

目录节点的状态字则由子项**按位 OR 聚合**（`FUN_140f4c670`，见 §4），
`expanded` 由 `FUN_140679890` 判别后在末尾 `local_50 += 1` 附加（状态值 = 2×逻辑状态 + Expanded）。

### 8.6 `tree+0x140` 比较模式枚举（谜题 #4 解答）

**写入链**（REA xrefs + corpus）：
```

    session+0x140 = mode
    if session+0x1b0 (回调对) 非空 → 调用 session+0x1b0(session+0x1b8, session)
```
