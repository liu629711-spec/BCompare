# SsRegistry.pas 规格（第一遍·架构级）

> 逆向来源：语料精读（122 函数；单元初始化 + 日期时间/本地化引擎已定性）。地址段 140500xxx–140505xxx。日期 2026-10-13。
> 单元身份：**BC 的本地化 / 日期时间格式 / 注册表访问引擎**（单元名 SsRegistry，实际主体 = 日期时间与区域设置）。

## 1. 核心发现：日期时间格式引擎

### 1.1 单元初始化 — `FUN_140500dd0`（1190B）
装载全局格式表（引用计数 DAT_141fe1ce0）：
- 日期格式串 **"dddd, MMMM dd, yyyy"**；日期分隔符 `,`（0x2c）
- 星期名表 Sunday…Saturday（全局槽 DAT_141fe1c90-cc0 连续 7 个字符串）
- 月份名/其他本地化常量（同段全局槽）

### 1.2 日期时间解析/格式化对（BC 自有格式，非 RTL）
- **ParseDateTime** `FUN_1405044a0(str) → double`（517B）：按**1 基位置**切字段——位置 1 宽 4（年）、6 宽 2（月）、9 宽 2（日）、12 宽 2（时）、15 宽 2（分）、18 宽 2（秒），逐段 FUN_140044f30 校验；返回 Delphi TDateTime double。
- **FormatDateTime** `FUN_1405046d0(out, dt)`：`yyyy-mm-dd hh":"nn":"ss`（格式串 @140504718 含哨兵值）；dt==哨兵 → 空串。
- **识别器** `FUN_140504910(str) → bool`（252B）：长度==19 且位置 5/8 为 `-`、11 为空格、14/17 为 `:`、逐字段数字校验（FUN_140504880）。
- **格式化包装** `FUN_1405051d0(out, str)` = Parse→Format 规范化往返。
- **当前时间** `FUN_140505130() → FILETIME`（GetSystemTime → FILETIME）。

**跨单元意义**：SsPersistent 的"特殊浮点"（tag 4 + 类 140003f18）实为 **TDateTime 选项**——配置里存 `yyyy-mm-dd hh:nn:ss` 字符串，解析/格式化即本单元 1405044a0/1405046d0（SsPersistent.md §2.2 相应更新理解：非时长/大小，是日期时间）。

### 1.3 时间比较与区间 — `FUN_140504b50(a, b, mode, ...)`（567B）
两串日期比较（先识别器校验）；mode 参数选择比较语义（早/晚/同）。配套 FUN_140504d90（校验）、FUN_140505180（字段提取）。

## 2. 注册表/区域设置访问

- `FUN_1405032c0`：注册表路径枚举（"LOCAL_MACHINE" 等根键 + DAT_1405033f8 键），逐级 FUN_140503210 匹配——**区域设置键解析**（HKEY_LOCAL_MACHINE\...\International 族）。
- `FUN_140503710(out, key, ...)`：键存在性/取值（FUN_140502960 查值）——疑为 GetLocaleInfo/注册表回退。
- `FUN_140503a30(str, out, len)`：宽串→定长缓冲（(n+1)*2 字节）。
- 值格式化：FUN_140504df0、FUN_140504a40、FUN_140502960 等（数值/枚举→显示串）。

## 2.5 实盘验证（2026-10-13）

- **FormatDateTime 实证**：BCState.xml `<TCheckForUpdatesState><LastChecked Value="2026-10-12 22:53:50"/>`——`yyyy-mm-dd hh:nn:ss` 格式串在真实配置文件中逐字符命中（1405046d0 的输出即此格式）。
- 报告 XML 的 `created="2026/10/13 9:24:12"` 用 `yyyy/mm/dd hh:nn:ss`（**另一个格式串**，格式引擎多格式输出能力的证据）。

## 3. 可测试锚点

1. Parse/Format 往返：`yyyy-mm-dd hh:nn:ss` 定长 19；非此形状识别器拒绝。
2. 字段越界（月>12 等）识别器行为（拒绝或回落）。
3. 星期/月名表 = 单元初始化装载的英文表（本地化可替换点）。
4. SsPersistent 日期选项：配置存格式串；未设值 = 哨兵 → 空串。
