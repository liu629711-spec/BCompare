# SsStrProcs.pas 规格（第一遍）

> 逆向来源：Ghidra 反编译 + PE 常量定位。原始源码 `C:\BCBuild\BCompare\Source\Ss\SsStrProcs.pas`。
> 91 个函数；本遍精读 6 个最大函数（全部 500B+）。全部是**可独立 oracle 测试的纯函数**——锚点价值最高的单元。

## 单元概览

字符串/数值/格式化工具库。无对象状态，全是静态函数。BC 界面上所有"人类可读"格式（时长、文件大小）和 Base64/URI 编码都出自这里。

## 已精读函数

### 1. 多进制数字解析 `FUN_1404fdac0(str, outVal, base, dollarHex)`
- base 参数（2–36 系）；`dollarHex=true` 时首字符 `$` → 强制 16 进制（Delphi 传统 `$FF`）
- 数字判定位图 `DAT_1404fddb8`（二进制实锤：**仅 '0'-'9'**，bits 48–57）；字母分支按 16 进制处理
- 结果按 base 位宽掩码截断（`0xffffffff >> ((8-base)*8)`，base<8 时）[?] 位宽语义待确认
- **BC 自己实现的 tolerant 数字解析**（格式化数字输入框的底层）

### 2. 时长格式化 `FUN_1404fc300(out, seconds)`
阈值（二进制实锤 DAT_1404fc570 = **60.0**）：
- `< 60s` → 小数秒格式
- `≥ 60s 且 < 3600s` → 分/秒两段式
- `≥ 3600s 且 < 24h`（0x5a0 分钟）→ 时/分两段式
- `≥ 24h` → 天/时两段式
- 格式串为**运行期延迟初始化变量**（指向 .bss 的指针，字面量在资源/语言层）——精确文本待 BC oracle 对拍实测

### 3. Base64 编码 `FUN_1404fbb60(out, bytes, len)`
- 标准字母表（常量 `u_..._141d0b7b8` = `A-Za-z0-9+/`），`=` 填充
- 3→4 字符主循环 + 余 1/余 2 尾部处理；输出 **UTF-16 字符串**（wchar_t 直接写）
- 零长度 → 输出空串

### 4. 百分号转义 `FUN_1404fd150(out, str, safeSet256bit)`
- 先转 UTF-8（`FUN_140015490(..., 0xfde9)`），按 256 位安全集位图统计需转义字符
- 每个非安全字符扩 2 字符（`%XX` 三字符替换）→ 分配 len+count*2
- **可配置安全集**的 URI escaper（会话 URL/路径处理用）[?] 调用方待确认

### 5. 文件大小格式化 `FUN_1404fbe90(out, bytes, thousandsMode)`
- thousandsMode=true → 原始整数 + 千分位分隔（`FUN_1404fc990`）
- 否则 1024 进制（除数二进制实锤）：KB=**1024.0**、MB=**1048576.0**、GB=**1073741824.0**、TB=**1099511627776.0**
- 阶梯阈值：0x400 / 0x100000 / 0x40000000 / 0x10000000000
- 数值经 FUN_1404fc610（浮点→字符串）——**小数位规则**在该函数里 [?]；格式串同上走运行期初始化，待 oracle 对拍

### 6. 接口数组定长 `FUN_1404fe0e0(arr, type, n)`
动态数组重定长 + 新槽位填默认接口引用（增引用计数）。

## 可测试行为锚点（全部可直接对拍）

1. Base64：空→空；"f"→"Zg=="；"fo"→"Zm8="；"foo"→"Zm9v"；"foobar"→"Zm9vYmFy"
2. 时长：59.9s → "59.9s" 系；61 → "1m 1s"；3661 → "1h 1m"；90000 → "1d 1h"
3. 文件大小：1023 → "1023 bytes"；1024 → "1.0 KB"；1048576 → "1.0 MB"；（小数位待确认后补精确期望值）
4. $hex：`$FF` + dollarHex → 255；`FF` 无前缀按 base 参数
5. 转义：安全集只含字母数字时，空格 → `%20`
6. 千分位：1234567 → "1,234,567"（分隔符按 locale [?]）
